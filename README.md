# 众生之门 · 灵境初行

第一阶段核心玩法原型：单人横版像素森林试炼。非官方主题玩法实验，全部图形由 Canvas 绘制。

## 已实现

- 猫形态，左右移动、二段跳、冲刺、灵爪近战。
- 御金远程攻击，凝冰冻结敌人，以及持续 9 秒的冰桥。
- 三枚灵印、普通敌人、守门者、检查点、死亡复苏、出口与通关。
- 键盘与触屏操作、暂停、帮助、可选合成音效、全屏按钮。
- 通关次数与最快用时保存在浏览器 localStorage；无账号或云存档。

## 操作

AD / 左右方向键：移动。Space / W / 上方向键：跳跃（可二段跳）。
J：灵爪。K：御金。L：凝冰。Shift：冲刺。Esc / P：暂停。Enter：开始、继续或复苏。

## 文件

- dist/engine.js：可独立测试的纯 JavaScript 模拟。
- dist/render.js：Canvas 像素画面与视差场景。
- dist/main.js：输入、页面状态、音效和本地纪录。
- dist/index.html、dist/style.css：界面。

## 验证

`node test-engine.mjs`

覆盖：着地、二段跳、冰桥生命周期、战斗、冻结与解冻、检查点、保留收集品的重生、通关条件、致命伤害优先于通关。
另有完整路线模拟：从默认出生状态，使用普通移动/跳跃/技能穿越森林、收集三枚灵印并通关，期间不修改位置、生命或奖励。

已运行 Node 语法检查及 Canvas 帧绘制检查。当前执行环境缺少受支持浏览器入口，未完成真实浏览器视觉与输入验证。
